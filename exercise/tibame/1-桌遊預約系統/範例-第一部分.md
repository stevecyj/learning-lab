# 桌遊預約系統（一）：用字典保存預約狀態

來源：[ex-part1.ipynb](ex-part1.ipynb)

這份練習用一個「文字指令介面」完成最小可行的桌遊預約系統。重點不在介面，而是把**資料狀態**、**指令判斷**與**字典操作**連起來。

## 學習目標

- 用字典表示「遊戲名稱 → 預約者」的關係。
- 用 `if` / `elif` 依使用者輸入分派功能。
- 用迴圈查詢、預約與取消預約。
- 看懂 `None` 在這個情境中代表「尚未預約」。

## 資料模型：遊戲名稱對應預約者

```python
games = {
    '小瓦隆': None,
    '雨聲': None,
    '龍捲風': None,
}
```

| 字典的 key | 字典的 value | 意義 |
| --- | --- | --- |
| `'小瓦隆'` | `None` | 這款遊戲尚未被預約 |
| `'小瓦隆'` | `'123abc'` | 這款遊戲由 ID 為 `123abc` 的使用者預約 |

`None` 不是字串 `'None'`，而是 Python 用來表示「沒有值」的特殊值，所以應使用 `is None` 判斷。

## 程式流程

```text
讀取訊息
  ├─ 想看遊戲種類 → 找出 value 是 None 的遊戲並列出
  ├─ 想預約＋遊戲名 → 檢查名稱存在且尚未預約，再寫入使用者 ID
  ├─ 想取消預約 → 找出目前使用者預約的遊戲，將 value 改回 None
  ├─ 結束 → 跳出迴圈
  └─ 其他訊息 → 顯示服務提示
```

主程式使用 `for i in range(1, 100)`，因此最多接收 99 次訊息；使用者輸入 `結束` 時由 `break` 提早離開。

## 三項核心操作

### 1. 顯示可預約遊戲

```python
game_list = []
for game, user_id in games.items():
    if user_id is None:
        game_list.append(game)
```

`games.items()` 一次給出一組 `(遊戲名稱, 預約者)`。只有預約者為 `None` 的遊戲才加入清單，接著再把清單組成多行文字輸出。

### 2. 預約指定遊戲

```python
game_name = msg[3:]
```

因為指令格式是「`想預約`＋遊戲名稱」，所以切片 `msg[3:]` 會去掉前三個字，留下遊戲名稱。例如 `想預約雨聲` 會得到 `'雨聲'`。

找到遊戲且尚未預約後，直接更新字典中該 key 的 value：

```python
games[game_name] = current_user_id
```

`found` 用來區分兩種失敗情況：名稱根本不存在，或名稱存在但已被其他人預約。

### 3. 取消目前使用者的預約

```python
if user_id == current_user_id:
    games[game] = None
```

程式逐一檢查每款遊戲；只要預約者是目前使用者，就把值還原成 `None`。依目前題目的寫法，同一使用者若預約多款遊戲，會一次全部取消。

## 手動演練

假設目前使用者是 `'123abc'`：

1. 輸入 `想看遊戲種類`：列出三款遊戲。
2. 輸入 `想預約雨聲`：`games['雨聲']` 由 `None` 改成 `'123abc'`。
3. 再輸入 `想看遊戲種類`：清單中不再有「雨聲」。
4. 輸入 `想取消預約`：`games['雨聲']` 改回 `None`。

## 讀程式時要留意的地方

- `msg[0:3] == '想預約'` 可辨認指令前綴；更容易閱讀的寫法是 `msg.startswith('想預約')`。
- `range(1, 100)` 不會包含 `100`。若沒有次數上限，`while True` 配合 `break` 更貼近這個互動式情境。
- 這版的資料只存在記憶體中；程式停止後，所有預約狀態都會消失。第二部分會改用 SQLite 保存資料。

## 補充

### 不限定「想預約」開頭時，如何取得遊戲名稱？

`msg[3:]` 的前提是輸入一定以「想預約」開頭。它只是無條件刪掉前三個字，不會確認被刪掉的是不是「想預約」。

若使用者可能輸入「我要玩雨聲」、「幫我訂雨聲」等不同句子，可以改為從 `games` 的已知遊戲名稱中尋找：

```python
matched_games = [
    game_name
    for game_name in games
    if game_name in msg
]

if len(matched_games) == 1:
    game_name = matched_games[0]
    print(f"找到遊戲：{game_name}")
elif len(matched_games) == 0:
    print("找不到遊戲名稱，請重新輸入")
else:
    print(f"找到多個遊戲：{', '.join(matched_games)}，請指定一個")
```

#### `matched_games` 為什麼可以這樣寫？

`matched_games` 是 Python 的**串列**（list）。其他語言常稱類似結構為 array（陣列），但 Python 這裡比較精確的名稱是 list。外層的 `[` 與 `]` 表示建立一個串列。

這種在 `[]` 內同時寫迴圈和條件的語法叫做**串列生成式**（list comprehension）：

```python
matched_games = [
    game_name              # 3. 條件成立時，放進新串列的值
    for game_name in games # 1. 逐一取出 games 的 key
    if game_name in msg    # 2. 檢查遊戲名稱有沒有出現在訊息中
]
```

閱讀時可以按照註解中的 `1 → 2 → 3` 理解。它等同於下面這個較長的寫法：

```python
matched_games = []

for game_name in games:
    if game_name in msg:
        matched_games.append(game_name)
```

逐行說明：

- `matched_games = []`：建立一個空串列，準備收集找到的遊戲。
- `for game_name in games:`：逐一取出 `games` 字典的 key，也就是每個遊戲名稱。
- `if game_name in msg:`：檢查 `game_name` 這段文字是否包含在 `msg` 中。例如 `'雨聲' in '我要玩雨聲'` 的結果是 `True`。
- `matched_games.append(game_name)`：把符合條件的遊戲名稱加到串列尾端。

因此，若 `games` 有「小瓦隆」、「雨聲」、「龍捲風」，而 `msg` 是 `'我要玩雨聲'`，最後會得到：

```python
matched_games = ['雨聲']
```

#### 後面的判斷在做什麼？

- `len(matched_games)` 取得串列內有幾個元素。
- `matched_games[0]` 取得第一個元素；Python 的索引從 `0` 開始。
- `elif` 是「前一個條件不成立時，再檢查這個條件」。
- `else` 在前面條件都不成立時執行；這裡表示找到兩個以上的遊戲名稱。
- `', '.join(matched_games)` 用逗號和空白連接多個遊戲名稱。

#### `print` 字串前的 `f` 是什麼？

```python
print(f"找到遊戲：{game_name}")
```

引號前的 `f` 代表這是 **f-string**（格式化字串）。Python 會計算 `{}` 內的變數或運算式，再把結果放入文字。

```python
game_name = '雨聲'
print(f"找到遊戲：{game_name}")
```

輸出為：

```text
找到遊戲：雨聲
```

沒有 `f` 時，`{game_name}` 只會被當成普通文字：

```python
print("找到遊戲：{game_name}")
# 輸出：找到遊戲：{game_name}
```

不過，只靠「遊戲名稱是否出現在訊息中」仍無法理解所有句子。例如使用者輸入錯字、簡稱，或同一句話提到多款遊戲，程式仍需要別名表或追問使用者。
