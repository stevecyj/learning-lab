# 桌遊預約系統（一）：改良版與完整講解

這份筆記不修改原本的 [範例-第一部分.md](範例-第一部分.md)，而是重新寫一個較完整的版本。

原程式使用 `msg[3:]` 取出遊戲名稱，因此使用者必須輸入「想預約＋遊戲名稱」。改良版先判斷使用者想做什麼，再從整句話中尋找已知的遊戲名稱。

## 完整程式

```python
games = {
    "小瓦隆": None,
    "雨聲": None,
    "龍捲風": None,
}

current_user_id = "123abc"


def find_game_names(message):
    """找出出現在使用者訊息中的遊戲名稱。"""
    matched_games = [
        game_name
        for game_name in games
        if game_name in message
    ]
    return matched_games


def show_available_games():
    """顯示所有尚未被預約的遊戲。"""
    available_games = [
        game_name
        for game_name, user_id in games.items()
        if user_id is None
    ]

    if len(available_games) == 0:
        print("目前沒有可預約的遊戲。")
    else:
        game_text = "\n".join(available_games)
        print(f"目前可預約的遊戲：\n{game_text}")


def reserve_game(message):
    """從訊息中找出遊戲，然後為目前使用者預約。"""
    matched_games = find_game_names(message)

    if len(matched_games) == 0:
        print("找不到遊戲名稱，請說明想預約哪一款遊戲。")
        return

    if len(matched_games) > 1:
        game_text = "、".join(matched_games)
        print(f"你提到了多款遊戲：{game_text}，請一次指定一款。")
        return

    game_name = matched_games[0]
    reservation_user_id = games[game_name]

    if reservation_user_id is None:
        games[game_name] = current_user_id
        print(f"已為你預約：{game_name}")
    elif reservation_user_id == current_user_id:
        print(f"你已經預約過：{game_name}")
    else:
        print(f"{game_name} 已被其他使用者預約。")


def cancel_reservations():
    """取消目前使用者的所有預約。"""
    canceled_games = []

    for game_name, user_id in games.items():
        if user_id == current_user_id:
            games[game_name] = None
            canceled_games.append(game_name)

    if len(canceled_games) == 0:
        print("你目前沒有預約。")
    else:
        game_text = "、".join(canceled_games)
        print(f"已取消預約：{game_text}")


def end_service():
    """顯示服務結束訊息。"""
    print("服務結束。")


def show_unknown_command():
    """顯示無法理解指令時的提示。"""
    print("我不明白這個指令。")
    print("你可以查看遊戲、預約遊戲、取消預約，或輸入「結束」。")


while True:
    msg = input("輸入訊息：").strip()

    if msg == "結束":
        end_service()
        break
    elif "取消" in msg:
        cancel_reservations()
    elif "預約" in msg or "訂" in msg:
        reserve_game(msg)
    elif "遊戲" in msg or "有哪些" in msg:
        show_available_games()
    else:
        show_unknown_command()
```

## 先理解程式如何運作

每次使用者輸入一句話，程式會按下列順序判斷：

1. 是不是要結束程式？
2. 句子中有沒有「取消」？
3. 句子中有沒有「預約」或「訂」？
4. 句子中有沒有「遊戲」或「有哪些」？
5. 都沒有的話，告訴使用者無法理解。

因此，下列輸入都可以觸發預約：

```text
想預約雨聲
我要預約雨聲
幫我訂雨聲
```

但「我要玩雨聲」不會自動預約，因為「玩」不一定代表「預約」。程式不應該在意圖不明確時擅自改變預約資料。

## 第一部分：用字典儲存預約狀態

```python
games = {
    "小瓦隆": None,
    "雨聲": None,
    "龍捲風": None,
}
```

`games` 是字典（dictionary）。每筆資料都有 key 和 value：

| key（鍵） | value（值） | 意思 |
| --- | --- | --- |
| `"雨聲"` | `None` | 雨聲尚未被預約 |
| `"雨聲"` | `"123abc"` | 雨聲由 `123abc` 這位使用者預約 |

`None` 是 Python 的特殊值，表示「沒有值」。它不是文字，所以不要寫成 `"None"`。

```python
current_user_id = "123abc"
```

`current_user_id` 代表正在使用系統的人。預約時，程式會把這個 ID 存入 `games`。

## 第二部分：從一句話中找遊戲名稱

```python
def find_game_names(message):
```

`def` 用來定義函式。函式可以把一組工作命名，以後只要呼叫這個名稱就能重複使用。

- `find_game_names` 是函式名稱。
- `message` 是參數，用來接收使用者的訊息。
- 結尾的 `:` 代表下一行開始是函式內容。
- 函式內容必須縮排。Python 使用縮排判斷哪些程式碼屬於函式。

### 串列生成式不是特殊的 array

```python
matched_games = [
    game_name
    for game_name in games
    if game_name in message
]
```

`matched_games` 是 Python 的串列（list）。某些程言語言會把類似的資料結構稱為 array（陣列），但 Python 這裡的名稱是 list。

這段語法叫做「串列生成式」（list comprehension）。它是建立串列的簡寫法。

先看意思完全相同的一般寫法：

```python
matched_games = []

for game_name in games:
    if game_name in message:
        matched_games.append(game_name)
```

實際執行順序是：

1. `matched_games = []`：先建立空串列。
2. `for game_name in games`：從 `games` 字典逐一取出 key。
3. `if game_name in message`：檢查遊戲名稱是否出現在訊息中。
4. `append(game_name)`：如果有出現，就把名稱加到串列尾端。

例如：

```python
message = "幫我預約雨聲"
```

迴圈會依序檢查：

```python
"小瓦隆" in "幫我預約雨聲"  # False
"雨聲" in "幫我預約雨聲"    # True
"龍捲風" in "幫我預約雨聲"  # False
```

所以最後的結果是：

```python
matched_games = ["雨聲"]
```

再回頭看簡寫：

```python
matched_games = [game_name for game_name in games if game_name in message]
```

可以用這個順序閱讀：

> 對於 `games` 中的每個 `game_name`，如果它出現在 `message` 中，就把 `game_name` 放進新串列。

```python
return matched_games
```

`return` 把結果交回給呼叫函式的地方。例如：

```python
result = find_game_names("我要預約雨聲")
```

函式找到 `["雨聲"]` 後，`result` 就會接到這個串列。

## 第三部分：顯示可預約遊戲

```python
available_games = [
    game_name
    for game_name, user_id in games.items()
    if user_id is None
]
```

`games.items()` 會同時取出字典的 key 和 value：

```python
game_name, user_id
```

例如第一次迴圈可能得到：

```python
game_name = "小瓦隆"
user_id = None
```

`if user_id is None` 只保留尚未預約的遊戲。

```python
game_text = "\n".join(available_games)
```

`"\n"` 是換行字元。`join()` 使用換行連接串列內的文字。

```python
available_games = ["小瓦隆", "雨聲", "龍捲風"]
game_text = "\n".join(available_games)
```

`game_text` 會變成：

```text
小瓦隆
雨聲
龍捲風
```

## 第四部分：處理預約

```python
matched_games = find_game_names(message)
```

先呼叫前面寫好的函式，取得所有匹配的遊戲。接下來有三種情況。

### 情況一：沒有找到

```python
if len(matched_games) == 0:
    print("找不到遊戲名稱，請說明想預約哪一款遊戲。")
    return
```

`len()` 會取得串列的元素數量。數量是 `0` 表示一款都沒找到。

這裡的 `return` 沒有帶回結果，用途是立即結束 `reserve_game()`，不要繼續執行下面的預約程式。

### 情況二：同時找到多款

```python
if len(matched_games) > 1:
```

`>` 是「大於」。當數量大於 `1`，程式不能擅自決定要預約哪款，因此請使用者重新指定。

### 情況三：只找到一款

```python
game_name = matched_games[0]
```

Python 的串列索引從 `0` 開始，所以 `[0]` 取出第一個元素。前面已處理「零個」和「多個」，執行到這裡時一定只剩一個。

```python
reservation_user_id = games[game_name]
```

使用遊戲名稱當作 key，取出字典中的預約者 ID。

- value 是 `None`：可以預約。
- value 等於 `current_user_id`：目前使用者已經預約。
- value 是其他 ID：已被其他人預約。

## 第五部分：f-string 是什麼？

```python
print(f"已為你預約：{game_name}")
```

字串前的 `f` 表示這是 f-string（formatted string literal）。`{}` 裡可以放變數或運算式，Python 會把計算結果放入文字。

```python
game_name = "雨聲"
print(f"已為你預約：{game_name}")
```

輸出：

```text
已為你預約：雨聲
```

若沒有 `f`：

```python
print("已為你預約：{game_name}")
```

Python 不會替換 `{game_name}`，而會原樣輸出：

```text
已為你預約：{game_name}
```

## 第六部分：取消預約

```python
canceled_games = []

for game_name, user_id in games.items():
    if user_id == current_user_id:
        games[game_name] = None
        canceled_games.append(game_name)
```

程式逐一檢查每款遊戲的預約者。如果預約者就是目前使用者：

1. 將字典的 value 改回 `None`，表示遊戲恢復為可預約。
2. 將遊戲名稱加入 `canceled_games`，稍後可以告訴使用者取消了哪些遊戲。

這個版本會取消目前使用者的所有預約，與原範例的規則一致。

## 第七部分：主迴圈

```python
while True:
```

`while` 會在條件成立時重複執行。`True` 永遠成立，因此這是無限迴圈。使用者可以不斷輸入訊息，直到程式執行 `break`。

```python
msg = input("輸入訊息：").strip()
```

- `input()` 顯示提示文字，然後等待使用者輸入。
- 使用者的輸入一定是字串。
- `.strip()` 清除字串開頭和結尾的多餘空白。

```python
if msg == "結束":
    end_service()
    break
elif "取消" in msg:
    cancel_reservations()
```

- `==` 比較左右兩邊是否完全相等。
- `in` 檢查一段文字是否包含在另一段文字中。
- `break` 結束整個 `while` 迴圈。
- `elif` 表示前一個條件不成立時，再檢查新條件。

判斷順序很重要。「取消預約」同時包含「取消」和「預約」，所以必須先檢查「取消」。如果先檢查「預約」，它會錯誤進入預約流程。

## 實際操作範例

```text
輸入訊息：有哪些遊戲？
目前可預約的遊戲：
小瓦隆
雨聲
龍捲風

輸入訊息：幫我訂雨聲
已為你預約：雨聲

輸入訊息：我要預約雨聲

```

## 這個版本仍然有什麼限制？

這不是真正的自然語言理解。程式只是尋找預先設定的關鍵字與遊戲名稱，因此：

- 輸入錯字時可能找不到遊戲。
- 輸入簡稱時，除非另外建立別名表，否則無法辨識。
- 「訂」只是簡單關鍵字，可能在其他句子中造成誤判。
- 同時提到多款遊戲時，程式會請使用者再選一款。
- 資料只存在記憶體中，程式結束後會消失。

對初學練習來說，這個版本的重點是學會將程式拆成「判斷意圖」、「尋找遊戲」與「改變預約狀態」三個步驟，而不是讓程式真的理解所有句子。
