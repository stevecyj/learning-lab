# 模組 25：SQLite Browser 介紹與安裝

## 這堂課在講什麼

本節介紹 SQLite Browser。它是一套用來觀察 SQLite 資料庫的工具，提供圖形化介面，方便查看資料庫中的資料表與資料值。

## 學完要會什麼

- 知道 SQLite Browser 的用途。
- 依自己的作業系統與位元數下載合適的版本。
- 在 Windows 上下載、解壓縮並啟動免安裝版 SQLite Browser。

## SQLite Browser 是什麼

SQLite Browser 是協助觀察 SQLite 資料庫的軟體。透過圖形化介面，可以查看資料庫裡的資料值、各個資料表，以及資料庫的結構。

課程建議使用這個工具協助觀察 SQLite 資料庫。

## 下載 SQLite Browser

1. 前往 SQLite Browser 的網站，開啟下載頁面。
2. 依自己的作業系統（OS）和位元數，選擇對應的安裝版本。
3. 課程建議下載 **No installer** 版本，也就是免安裝版。

以講師的電腦為例：使用 Windows 64 位元，因此下載 Windows 64 位元的 **No installer** 版本。

## Windows 免安裝版的啟動方式

下載完成後，先把壓縮檔放到資料夾中，再進行解壓縮。

解壓縮完成後：

1. 開啟解壓縮後的資料夾。
2. 找到 `DB Browser for SQLite.exe`。
3. 連按兩下這個檔案，即可開啟 SQLite Browser。

## 注意事項

- 下載版本必須符合自己的作業系統與位元數。
- 本節示範的是 Windows 64 位元的免安裝版；其他作業系統的下載項目應依下載頁提供的版本選擇。

## 一句話回顧

SQLite Browser 讓我們透過圖形化介面查看 SQLite 資料庫；Windows 使用者可下載 64 位元的免安裝版，解壓縮後執行 `DB Browser for SQLite.exe`。
