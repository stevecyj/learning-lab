# 3-5 攝氏與華氏溫度轉換練習

## 學習目標

完成這一節後，我應該能夠：

1. 把攝氏溫度轉換成華氏溫度。
2. 記住 `input()` 回傳的是字串，計算前必須轉型。
3. 正確使用 `9 / 5` 與括號表達溫度轉換公式。
4. 根據輸入是否可能有小數，在 `int()` 與 `float()` 之間做選擇。
5. 用冰點、沸點與負溫驗證程式結果。
6. 把輸入、計算與輸出分開，讓程式更容易檢查。

---

## 一、題目要做什麼？

這個練習要求使用者輸入一個攝氏溫度，再由程式換算成華氏溫度。

可以先把題目拆成三步：

```text
輸入攝氏溫度
→ 套用轉換公式
→ 顯示華氏溫度
```

攝氏轉華氏的公式是：

```text
華氏溫度 = 攝氏溫度 × 9 / 5 + 32
```

用 Python 表示：

```python
fahrenheit = celsius * 9 / 5 + 32
```

字幕說的「乘以五分之九」就是乘以 `9 / 5`，不是 `5 / 9`。中文分數「五分之九」的分母是 5、分子是 9。

---

## 二、先完成固定數值版本

剛開始寫計算程式時，可以先不用 `input()`，直接放入一個已知數值：

```python
celsius = 20
fahrenheit = celsius * 9 / 5 + 32

print(f"攝氏 {celsius}°C 等於華氏 {fahrenheit}°F")
```

輸出：

```text
攝氏 20°C 等於華氏 68.0°F
```

手算過程如下：

```text
20 × 9 / 5 + 32
= 36 + 32
= 68
```

先用固定數值確認公式，再加入使用者輸入，可以把「公式錯誤」和「輸入錯誤」分開排查。

---

## 三、加入 `input()` 與型別轉換

`input()` 不論讀到什麼，都會回傳 `str`：

```python
celsius_text = input("請輸入攝氏溫度：")
print(type(celsius_text))  # <class 'str'>
```

字串不能直接和數字進行這個公式的乘除運算，因此要先轉型。字幕使用 `int()`：

```python
celsius = int(input("請輸入攝氏溫度："))
fahrenheit = celsius * 9 / 5 + 32

print(f"華氏溫度：{fahrenheit}°F")
```

這可以處理 `20`、`0` 或 `-10`，卻不能接受 `20.5`。溫度可能有小數，所以一般會使用 `float()`：

```python
celsius = float(input("請輸入攝氏溫度："))
fahrenheit = celsius * 9 / 5 + 32

print(f"華氏溫度：{fahrenheit:.1f}°F")
```

輸入 `20.5` 時，結果是：

```text
華氏溫度：68.9°F
```

`:.1f` 只把顯示結果格式化成小數點後一位，不會改變 `fahrenheit` 變數中原本的值。

---

## 四、公式中的順序與括號

正確公式是：

```python
fahrenheit = celsius * 9 / 5 + 32
```

也可以用括號強調轉換比例：

```python
fahrenheit = celsius * (9 / 5) + 32
```

這兩行結果相同。Python 會先做乘除，再做加法；同一優先順序的乘除會由左向右計算。

下面的寫法則不相同：

```python
wrong = celsius * 9 / (5 + 32)
```

括號會要求先計算 `5 + 32`，因此改變了公式。括號不是裝飾，而是在表達計算結構。

也不要把比例顛倒成 `5 / 9`：

```python
wrong = celsius * 5 / 9 + 32
```

`5 / 9` 是華氏轉攝氏公式會使用的比例之一，不是攝氏轉華氏的比例。

## 五、用已知溫度驗算

程式能執行，不代表公式一定正確。可以用幾個已知對應值檢查：

| 攝氏 | 預期華氏 | 用途 |
|---:|---:|---|
| `0°C` | `32°F` | 水的冰點 |
| `20°C` | `68°F` | 教材範例 |
| `100°C` | `212°F` | 標準大氣壓下水的沸點 |
| `-40°C` | `-40°F` | 兩種刻度相同的特殊點 |

可以一次執行多組測試：

```python
test_values = [0, 20, 100, -40]

for celsius in test_values:
    fahrenheit = celsius * 9 / 5 + 32
    print(f"{celsius:>4}°C → {fahrenheit:>6.1f}°F")
```

現階段不必先記住 `for` 迴圈與格式寬度的所有細節；這段程式的用途是示範不要只測一筆資料。

> 冰點與沸點會受壓力等條件影響。這裡的 `0°C` 與 `100°C` 是入門公式常用、以標準大氣壓為前提的檢查值。

## 六、讓輸入錯誤不致中斷程式

如果使用者輸入 `abc`，`float("abc")` 會產生 `ValueError`。可以加入基本錯誤處理：

```python
try:
    celsius = float(input("請輸入攝氏溫度："))
    fahrenheit = celsius * 9 / 5 + 32
    print(f"華氏溫度：{fahrenheit:.1f}°F")
except ValueError:
    print("輸入錯誤：請輸入數字，例如 20 或 20.5。")
```

這段程式把可能失敗的轉型放進 `try`，並在轉型失敗時提供可採取行動的訊息。

## Python 專家關注的點

1. **公式方向要正確**：攝氏轉華氏使用 `C × 9 / 5 + 32`；反向轉換不能直接沿用。
2. **輸入邊界要處理**：`input()` 回傳字串，使用者也可能輸入空白或非數字文字。
3. **型別要符合問題**：`int()` 只適合題目明確限制為整數時；一般溫度輸入以 `float()` 更實用。
4. **名稱要表達意義**：`celsius` 與 `fahrenheit` 比 `c`、`f` 或 `a`、`b` 更容易閱讀與維護。
5. **計算和顯示要分開**：先保留完整計算結果，最後再用 `:.1f` 或 `:.2f` 控制畫面上的精度。
6. **單位要清楚標示**：輸入提示與輸出都應寫出 `°C`、`°F`，避免只有數字卻不知道刻度。
7. **測試要選有辨識力的值**：`0`、`100` 與 `-40` 能快速發現比例、加數或負號是否寫錯。
8. **不要只看程式有沒有報錯**：寫反 `9 / 5` 與 `5 / 9` 仍能順利執行，卻會得到錯誤答案。
9. **進階程式可分離純計算邏輯**：把轉換寫成函式後，不依賴鍵盤輸入也能測試，更方便重用。

例如：

```python
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32
```

## 本節重點

這一節最重要的流程是：

> 讀取攝氏文字 → 轉成 `float` → 套用 `C × 9 / 5 + 32` → 標示華氏單位 → 用已知值驗算。

`20°C → 68°F` 只是其中一個範例。真正可靠的做法，是同時測試一般值、零、負數、小數與不合法文字，確認公式和輸入處理都符合預期。
