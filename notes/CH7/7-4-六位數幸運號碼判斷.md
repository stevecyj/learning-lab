## 一、題目規則

請使用者輸入一個六位數整數。若前三個位數的總和等於後三個位數的總和，就輸出 `lucky number`；否則輸出 `regular number`。

以 `123321` 為例：

~~~text
前三位：1 + 2 + 3 = 6
後三位：3 + 2 + 1 = 6
~~~

兩邊都是 6，所以 `123321` 是 `lucky number`。

再看 `123456`：

~~~text
前三位：1 + 2 + 3 = 6
後三位：4 + 5 + 6 = 15
~~~

6 不等於 15，所以 `123456` 是 `regular number`。

> 教材字幕一度把 `regular number` 說成「前三位總和等於後三位總和」，但依題目與程式邏輯，這其實是 `lucky number` 的定義。

## 二、解法一：用 `%` 和 `//` 取出各個位數

先把輸入轉成整數：

~~~python
number = int(input("請輸入一個六位數整數："))
~~~

### `%` 取得餘數，`//` 做整數除法

若 `number = 123456`：

| 算式 | 結果 | 取出的位數 |
| --- | ---: | --- |
| `number % 10` | `6` | 個位 |
| `number % 100 // 10` | `5` | 十位 |
| `number % 1000 // 100` | `4` | 百位 |
| `number % 10000 // 1000` | `3` | 千位 |
| `number % 100000 // 10000` | `2` | 萬位 |
| `number // 100000` | `1` | 十萬位 |

以十位數為例：

~~~python
123456 % 100       # 56，先保留最後兩位
56 // 10           # 5，再去掉個位
~~~

把六個位數分成兩組加總：

~~~python
number = int(input("請輸入一個六位數整數："))

first_sum = (
    number // 100000
    + number % 100000 // 10000
    + number % 10000 // 1000
)

last_sum = (
    number % 1000 // 100
    + number % 100 // 10
    + number % 10
)

if first_sum == last_sum:
    print("lucky number")
else:
    print("regular number")
~~~

`%` 和 `//` 的優先順序相同，會由左至右計算。可以加上括號，明確標出哪一步先保留位數、哪一步再移除位數：

~~~python
tens = (number % 100) // 10
~~~

## 三、解法二：保留輸入字串，再用索引取值

`input()` 回傳字串。保留這個型別，就能用索引取出每個字元，再交給 `int()` 轉成整數：

~~~python
number_text = input("請輸入一個六位數整數：")

first_sum = (
    int(number_text[0])
    + int(number_text[1])
    + int(number_text[2])
)

last_sum = (
    int(number_text[3])
    + int(number_text[4])
    + int(number_text[5])
)

if first_sum == last_sum:
    print("lucky number")
else:
    print("regular number")
~~~

Python 的索引從 `0` 開始。輸入 `"123456"` 時，各索引對應如下：

| 索引 | `[0]` | `[1]` | `[2]` | `[3]` | `[4]` | `[5]` |
| --- | --- | --- | --- | --- | --- | --- |
| 字元 | `"1"` | `"2"` | `"3"` | `"4"` | `"5"` | `"6"` |

索引取出的是「字元」，每個字元代表一個十進位位數。教材口語中的「位元」指的是 bit，不適合用來稱呼這些字元。

### 字元要先轉成 `int` 才能相加

字串的 `+` 會串接內容，不會進行數值加法：

~~~python
print("1" + "2" + "3")                  # 123
print(int("1") + int("2") + int("3"))   # 6
~~~

## 四、`if`、`else` 與縮排

條件判斷的基本結構如下：

~~~python
if 條件:
    條件成立時執行的程式
else:
    條件不成立時執行的程式
~~~

套用到這一題：

~~~python
if first_sum == last_sum:
    print("lucky number")
else:
    print("regular number")
~~~

寫條件判斷時要注意：

- `==` 用來比較兩個值是否相等。
- `if` 條件和 `else` 後面都要有冒號 `:`。
- `print()` 前面的縮排表示它屬於哪個條件區塊；Python 通常使用 4 個空白。

不要把比較運算子 `==` 和指定運算子 `=` 混在一起：

~~~python
first_sum = 6          # 把 6 指派給 first_sum
first_sum == last_sum  # 比較兩者是否相等，結果是 True 或 False
~~~

參考：[Python 官方教學：`if` Statements](https://docs.python.org/3/tutorial/controlflow.html#if-statements)

## 五、兩種解法怎麼選

| 比較項目 | 整數運算 | 字串索引 |
| --- | --- | --- |
| 輸入後的型別 | `int` | `str` |
| 主要工具 | `%`、`//` | `[]`、`int()` |
| 優點 | 練習十進位拆位數與算術 | 與題意接近，較容易讀懂 |
| 需注意 | 各位數的除數容易寫錯 | 索引可能越界，字元可能不是數字 |

想練習餘數和整數除法，可以用第一種。若只需要處理固定長度的輸入，字串索引通常比較直觀。

學過串列生成式、切片與 `sum()` 後，字串版本可以縮短：

~~~python
number_text = input("請輸入一個六位數整數：")
digits = [int(char) for char in number_text]

if sum(digits[:3]) == sum(digits[3:]):
    print("lucky number")
else:
    print("regular number")
~~~

這些語法若還不熟，先用前面的逐項相加版本即可。

## 六、題目假設與實際程式的輸入檢查

教材先假設使用者會輸入六個數字，讓練習集中在拆位數和條件判斷。

實際讓別人使用時，輸入可能少於六位、超過六位，或含有非數字字元。字串解法可以先檢查：

~~~python
number_text = input("請輸入一個六位數整數：")

if len(number_text) != 6 or not number_text.isdigit():
    print("輸入格式錯誤")
else:
    first_sum = int(number_text[0]) + int(number_text[1]) + int(number_text[2])
    last_sum = int(number_text[3]) + int(number_text[4]) + int(number_text[5])

    if first_sum == last_sum:
        print("lucky number")
    else:
        print("regular number")
~~~

`isdigit()` 會檢查字串是否非空，而且每個字元都是數字。某些非 ASCII 字元也會通過這項檢查；若規格只允許 `0` 到 `9`，需要改用更嚴格的判斷。

參考：[Python 官方文件：`str.isdigit()`](https://docs.python.org/3/library/stdtypes.html#str.isdigit)

## 本節教材補充

| 教材說法 | 修正或補充 |
| --- | --- |
| `regular number` 是前三位總和等於後三位總和 | 依題意，總和相等的是 `lucky number`；不相等才是 `regular number` |
| 用運算把「位元」取出來 | 這裡取出的是十進位的「位數」；bit 才是電腦資料中的「位元」 |
| 字串方法取出第一、第二、第三個「位元」 | 更精確的說法是用索引取出第一、第二、第三個「字元」 |
| `if s1 == s2` 時輸出 lucky number | 正確；`==` 是相等比較，且條件後要加冒號，所屬程式碼要縮排 |
| 題目要求輸入六位數 | 教材程式以輸入正確為前提；實際程式可再驗證長度與是否全為數字 |
