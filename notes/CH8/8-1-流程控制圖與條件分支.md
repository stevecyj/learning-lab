## 一、什麼是流程控制？

程式通常由上到下依序執行；但遇到條件時，程式必須決定下一步要走哪一條路。**流程控制**就是用來指定「哪些程式區塊要在什麼條件下執行」的機制。

例如：

- 分數達到 60 分才顯示「及格」。
- 使用者已登入才允許查看個人資料。
- 庫存不足時顯示缺貨訊息。

條件運算式會得到 `True` 或 `False`，Python 的 `if` 依據這個結果選擇要不要執行縮排內的程式碼。

```python
score = 75

if score >= 60:
    print("及格")

print("成績查詢結束")
```

因為 `score >= 60` 為 `True`，所以會輸出：

```text
及格
成績查詢結束
```

若 `score = 50`，條件為 `False`，`print("及格")` 會被跳過，但條件後的 `print("成績查詢結束")` 仍會執行。

## 二、用流程圖先看懂分支

流程圖能把程式的執行順序和分岔條件畫出來。在流程圖中，**箭頭**表示流程前進的方向。

```text
開始
  ↓
執行條件前的敘述
  ↓
◇ 條件成立嗎？
 ├─ 是 → 執行條件內的敘述
 │             ↓
 └─ 否 ───────┤
               ↓
       執行條件後的敘述
               ↓
              結束
```

這張圖描述的重點是：只有「條件內的敘述」會依條件決定是否執行；兩條路最後都會接回條件後的敘述。

### 常見流程圖符號

| 圖形 | 代表意義 | 例子 |
| --- | --- | --- |
| 圓角長方形／橢圓形 | 開始或結束（終止） | 程式開始、程式結束 |
| 長方形 | 程序（process） | 計算總價、更新變數 |
| 菱形 | 條件判斷（decision） | `score >= 60` 是否成立？ |
| 平行四邊形 | 輸入或輸出（input/output） | `input()`、`print()` |
| 箭頭 | 流程方向 | 由判斷走向「是」或「否」 |

> 不同教材的圖示樣式可能略有差異；重點是依箭頭追蹤流程，並在菱形判斷處確認每個分支的條件。

## 三、流程圖如何對應 `if`

上述「條件成立才執行」的流程，在 Python 中寫成：

```python
if 條件:
    條件成立時要執行的程式碼

條件判斷後仍要執行的程式碼
```

例如：

```python
temperature = 32

if temperature > 30:
    print("天氣炎熱，記得補充水分。")

print("出門前確認天氣。")
```

| 流程圖概念 | Python 寫法 |
| --- | --- |
| 菱形中的條件 | `if temperature > 30:` |
| 「是」分支的程序 | 縮排的 `print("天氣炎熱，記得補充水分。")` |
| 判斷後匯合的程序 | 未縮排的 `print("出門前確認天氣。")` |

`if` 行尾的冒號 `:` 和下一行的縮排都是 Python 語法的一部分。縮排表示哪些敘述屬於這個條件區塊。

參考：[Python 官方文件：`if` statement](https://docs.python.org/3/reference/compound_stmts.html#the-if-statement)

## 四、`if`、`else`、`elif` 的角色

本模組接下來會介紹三種分支：

```python
if 條件一:
    # 條件一為 True 時執行
elif 條件二:
    # 條件一為 False，且條件二為 True 時執行
else:
    # 前面條件都不成立時執行
```

- `if`：先判斷第一個條件。
- `elif`：當前一個條件不成立時，再檢查另一個條件；可以有零個或多個。
- `else`：前面所有條件都不成立時的預設處理；可以省略，而且最多一個。

範例：

```python
score = 82

if score >= 90:
    print("優秀")
elif score >= 60:
    print("及格")
else:
    print("需要加強")
```

Python 由上往下檢查條件，找到第一個 `True` 後便執行該區塊，並跳過同一組 `if`／`elif`／`else` 中其餘區塊。因此條件的排列順序很重要。

## 五、巢狀流程控制預告

當某個分支裡還需要做下一層判斷時，可以在該區塊內再寫一個 `if`，這稱為**巢狀流程控制**：

```python
is_member = True
purchase_amount = 1_200

if is_member:
    if purchase_amount >= 1_000:
        print("會員可享折扣")
```

內層 `if` 只有在 `is_member` 為 `True` 時才會被檢查。巢狀結構適合表達「必須先符合前提，才需要判斷下一個條件」的情境；後續章節會實作它。

## 六、快速自我檢查

不執行程式，先回答下列問題：

```python
age = 16

if age >= 18:
    print("可以投票")

print("年齡資料已確認")
```

1. `age >= 18` 的結果是什麼？
2. 哪一行 `print()` 不會執行？
3. 最後會顯示什麼訊息？

答案：

1. `False`
2. `print("可以投票")`
3. `年齡資料已確認`

## 重點整理

1. 流程控制讓程式依條件決定是否執行特定區塊。
2. 流程圖的箭頭表示方向；菱形表示判斷；長方形表示程序；平行四邊形表示輸入／輸出；圓角圖形表示開始或結束。
3. `if` 的條件為 `True` 時才會執行縮排區塊；判斷後的未縮排敘述會照正常流程繼續執行。
4. `elif` 用於追加條件，`else` 用於所有條件皆不成立的情況。
5. 巢狀 `if` 表示先通過外層條件，才進行內層判斷。
