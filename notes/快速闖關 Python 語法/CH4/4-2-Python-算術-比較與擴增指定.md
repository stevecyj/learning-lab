## 一、先把名詞說對：operator 不是 operand

字幕將 operator 譯成「運算元」，這會把兩個不同概念混在一起。在這份筆記中統一使用：

- operator：運算子，表示要進行的操作。
- operand：運算元，表示參與運算的值或運算式。

```python
3 + 6
```

- `+` 是運算子。
- `3` 與 `6` 是運算元。

字幕將 Python 常見運算分成七類：

| 類別 | 常用中文 | 範例 |
| --- | --- | --- |
| Arithmetic | 算術運算 | `a + b`、`a // b` |
| Comparison | 比較運算 | `a == b`、`a < b` |
| Assignment | 指定與擴增指定 | `a = b`、`a += b` |
| Logical | 邏輯運算 | `a and b`、`not a` |
| Membership | 成員測試 | `x in items` |
| Identity | 同一性測試 | `a is b` |
| Bitwise | 位元運算 | `a & b`、`a << 1` |

這七類是初學教材常用的整理方式，並非 Python 語法的唯一分類法。例如，Python 語言參考將 `in`、`is` 和 `<` 等都歸在 comparisons，普通 `=` 則歸在 assignment statements（指定語句）。

這一節先處理字幕實際示範的三組：算術、比較與擴增指定。

## 二、算術運算子

### 基本符號

| 運算子 | 用途 | 範例 | 結果 |
| --- | --- | --- | --- |
| `+` | 加法 | `25 + 5` | `30` |
| `-` | 減法 | `5 - 10` | `-5` |
| `*` | 乘法 | `3 * 3` | `9` |
| `/` | 除法 | `10 / 3` | `3.3333333333333335` |
| `%` | 餘數 | `10 % 3` | `1` |
| `**` | 次方 | `3 ** 3` | `27` |
| `//` | 向下取整除法 | `10 // 3` | `3` |

```python
print(25 + 5)
print(5 - 10)
print(3 * 3)
print(10 / 3)
print(10 % 3)
print(3 ** 3)
print(10 // 3)
```

### `/` 不是只保留兩位小數

字幕將 `10 / 3` 簡寫為 `3.33`。實際執行這行程式時，Python 顯示的 `float` 結果是：

```python
print(10 / 3)  # 3.3333333333333335
```

如果需要指定顯示位數，應明確格式化：

```python
result = 10 / 3
print(f"{result:.2f}")  # 3.33
```

格式化只改變輸出的字串；`result` 仍是原本的 `float`。

### `//` 是向下取整，不是單純刪掉小數

`//` 常被簡稱為「整數除法」，但這個名稱容易造成兩個誤解。

第一，它會將數學除法的結果向負無窮大方向取整：

```python
print(10 // 3)   # 3
print(-10 // 3)  # -4
```

`-10 / 3` 約為 `-3.333...`，向下取整得到 `-4`，不是刪掉小數後的 `-3`。

第二，在 `int` 與 `float` 的運算中，只要一邊是 `float`，結果也是 `float`：

```python
print(10.0 // 3)        # 3.0
print(type(10.0 // 3))  # <class 'float'>
```

所以更準確的名稱是 floor division（向下取整除法）。

### `%` 和 `//` 是一組的

對這一節使用的整數 `x` 與非零整數 `y`，餘數與向下取整除法符合：

```text
x == (x // y) * y + (x % y)
```

例如：

```python
x = 10
y = 3

print(x // y)                         # 3
print(x % y)                          # 1
print((x // y) * y + (x % y) == x)   # True
print(divmod(x, y))                   # (3, 1)
```

`divmod(x, y)` 一次回傳商與餘數，結果等於 `(x // y, x % y)`。負數的結果也要用同一關係理解：

```python
print(divmod(-10, 3))  # (-4, 2)
```

不要只背 `-10 % 3` 是 `2`；用等式驗算：

```text
-10 == (-4) * 3 + 2
```

### 除數為零會發生例外

```python
print(10 / 0)   # ZeroDivisionError
print(10 // 0)  # ZeroDivisionError
print(10 % 0)   # ZeroDivisionError
```

測試除法時，除了一般正數範例，還要檢查除數為零、運算元為負數與型別不相容的情況。

### 運算子的意義由型別決定

`+` 和 `*` 不只能用於數字：

```python
print("Py" + "thon")  # Python
print("ha" * 3)        # hahaha
```

這不是 Python 在任意猜測轉型，而是 `str` 型別本來就定義了這些操作。如果型別沒有定義對應的運算，就會發生 `TypeError`：

```python
print("9" + 1)  # TypeError
```

## 三、運算優先順序決定先算什麼

```python
print(2 + 3 * 4)    # 14
print((2 + 3) * 4)  # 20
```

在這一節的符號中，可先記住以下相對順序：

1. 括號 `()`
2. 次方 `**`
3. 正負號 `+x`、`-x`
4. `*`、`/`、`//`、`%`
5. `+`、`-`
6. 比較運算

`**` 和一元負號的關係特別容易讀錯：

```python
print(-3 ** 2)    # -9，先算 3 ** 2
print((-3) ** 2)  # 9
print(2 ** -1)    # 0.5
```

`**` 左邊的一元負號會後算，但右邊可以直接寫一元負號，所以 `2 ** -1` 合法且結果是 `0.5`。不確定時就加上括號；即使記得優先順序，括號也能減少誤讀。

## 四、比較運算子比較的是物件，不只是數字

| 寫法 | 問題 |
| --- | --- |
| `a == b` | 兩邊的值是否相等？ |
| `a != b` | 兩邊的值是否不相等？ |
| `a < b` | `a` 是否小於 `b`？ |
| `a <= b` | `a` 是否小於或等於 `b`？ |
| `a > b` | `a` 是否大於 `b`？ |
| `a >= b` | `a` 是否大於或等於 `b`？ |

```python
x = 10
y = 2

print(x == y)  # False
print(x != y)  # True
print(x > y)   # True
print(x <= y)  # False
```

對一般內建型別，這些比較會得到 `True` 或 `False`。但「比較兩個數字」的說法太窄：

```python
print("apple" == "apple")  # True
print([1, 2] == [1, 2])     # True
print("apple" < "banana")  # True
```

型別決定了它支援哪些比較，以及「值相等」或「順序」是什麼意思。有些物件可以比較相等，卻不能排序：

```python
print({"name": "Ada"} == {"name": "Ada"})  # True
print({"name": "Ada"} < {"name": "Bob"})   # TypeError
```

### `=` 和 `==` 回答的問題不同

```python
x = 10          # 指定：讓名稱 x 綁定到結果物件
print(x == 10)  # 比較：x 參照的值是否等於 10
```

- `=` 改變名稱與物件的綁定。
- `==` 求值後產生比較結果。

Python 語言參考將普通 `=` 放在 assignment statements（指定語句）中，而不是一般運算式的 operator precedence 表中。初學者可以看懂教材所說的「assignment operator」，但寫筆記時用「指定」會更準確。

### Python 支援連鎖比較

```python
age = 20

print(18 <= age < 65)  # True
```

這類寫法接近數學習慣，其意義類似：

```python
print(18 <= age and age < 65)
```

差異是連鎖比較中間的運算式最多只會求值一次。實作區間條件時，`minimum <= value <= maximum` 通常比重複寫 `value` 更清楚。

### 進階邊界：自訂型別可定義比較行為

對於一般 Python 內建型別，把比較結果視為 `bool` 就足夠應付目前練習。不過 Python 允許自訂型別定義 `__eq__()`、`__lt__()` 等方法，這些方法甚至可以回傳非 `bool` 物件。

現階段不必自己實作這些方法。先記住：一般內建型別的比較結果是 `True` 或 `False`；「比較一定回傳內建 `bool`」則不適用於所有 Python 物件。

## 五、擴增指定不只是少打幾個字

### 數字範例中，兩種寫法產生相同數值

```python
x = 5
x = x + 3
print(x)  # 8
```

可以寫成：

```python
x = 5
x += 3
print(x)  # 8
```

常見對應如下：

| 擴增指定 | 相似的展開寫法 |
| --- | --- |
| `x += y` | `x = x + y` |
| `x -= y` | `x = x - y` |
| `x *= y` | `x = x * y` |
| `x /= y` | `x = x / y` |
| `x //= y` | `x = x // y` |
| `x %= y` | `x = x % y` |
| `x **= y` | `x = x ** y` |

字幕中的「`x += 3` 完全等價於 `x = x + 3`」對這個 `int` 範例的最後數值成立，但不能套用到所有 Python 物件。

### 不可變物件：計算後重新綁定

`int` 是不可變型別。對 `int` 執行 `+=` 時，不會把原本的整數物件改大，而是讓名稱重新綁定到結果物件：

```python
x = 5
old_value = x

x += 3

print(x)               # 8
print(old_value)       # 5
print(x is old_value)  # False
```

不要說「把 `3` 覆寫回數字 `5` 裡」。沿用上一節的物件模型會更一致：先運算，再讓 `x` 綁定到結果物件。

### 可變物件：`+=` 可能直接修改原物件

先預測以下結果：

```python
first = [1, 2]
alias = first

first += [3]

print(first)           # [1, 2, 3]
print(alias)           # [1, 2, 3]
print(first is alias)  # True
```

內建 list 的 `+=` 會就地擴充原 list，所以 `alias` 也看得到新元素。

再改用普通加法與指定：

```python
first = [1, 2]
alias = first

first = first + [3]

print(first)           # [1, 2, 3]
print(alias)           # [1, 2]
print(first is alias)  # False
```

`first + [3]` 建立新 list，之後 `first` 改綁定到新 list；`alias` 仍指向原本的 list。

除了可能就地修改物件，擴增指定還會讓左側目標只求值一次。因此，官方文件明確說明 `x += y` 與 `x = x + y` 只是效果相似，並非完全等價。

## 六、字幕內容需要修正的地方

1. **operator 應譯為運算子**：運算元是 operand，也就是參與運算的值或運算式。
2. **Arithmetic Operator 通常稱為算術運算子**：「計算運算元」同時混淆了中英文名詞。
3. **`10 / 3` 不是剛好等於 `3.33`**：Python 的 `float` 結果通常顯示為 `3.3333333333333335`；`3.33` 是格式化或口頭近似值。
4. **`//` 不是無條件捨去小數**：它是向下取整除法，因此 `-10 // 3` 是 `-4`。
5. **`//` 的結果不一定是 `int`**：`10.0 // 3` 的結果是 `3.0`，型別是 `float`。
6. **比較運算不只比較數字**：字串、list 與其他物件也可以定義比較行為。
7. **「比較一定回傳 `bool`」是初學簡化**：一般內建型別的範例會得到 `True` 或 `False`，但自訂比較方法可回傳其他物件。
8. **普通 `=` 更準確地說是指定語句的語法**：不要和值比較 `==` 混淆。
9. **`x += 3` 與 `x = x + 3` 不是在所有情況下都完全一樣**：擴增指定可能就地修改可變物件，且左側目標只會求值一次。
10. **字幕的 `x = x + 3` 曾轉錄成 `x = +3`**：後者只是將正數 `3` 指定給 `x`，並不會加上舊值。
11. **`s = 10` 應為口誤或轉錄錯誤**：該段後續比較的是 `x > y`，範例應是 `x = 10`、`y = 2`。

## 七、熟悉 Python 的開發者在乎的是什麼

### 1. 先問運算元是什麼型別

同一個 `+` 可以表示數字加法、序列串接，也可由自訂型別定義新行為。看到運算式時，不只看符號，還要看兩邊物件的型別。

### 2. 用正確語意預測邊界值

`//` 是 floor division，所以負數不能用「刪掉小數」預測。`%` 則應與 `//` 一起用等式驗算。準確的心智模型能處理新題目，口訣通常只能處理教材中的正數範例。

### 3. 分清重新綁定與就地修改

對 `int` 執行 `+=` 會讓名稱重新綁定；list 的 `+=` 通常會修改原 list。當多個名稱參照同一可變物件時，這個差異會直接影響程式正確性。

### 4. 讓程式碼清楚表達意圖

`18 <= age < 65` 能直接表達區間；複雜運算式加括號則可以減少誤讀。記住優先順序很重要，讓下一個維護者容易讀懂也一樣重要。

### 5. 同時測試正常與邊界情況

對除法測試零與負數，對比較測試相同與不同型別，對 `+=` 測試共用 list。這些小實驗能比只重跑課堂範例更快暴露錯誤理解。

## 本節重點

> 不要只背符號。先看運算元的型別，再按運算子語意與優先順序預測結果。`//` 是向下取整，`=` 是指定，`==` 是值比較；`+=` 可能重新綁定，也可能就地修改物件。

這些概念之後會用在條件判斷、資料清理、計數器、分頁邏輯與 list 處理。養成「先預測、再執行、最後解釋差異」的習慣，有助於提早發現對型別或運算語意的誤解。
