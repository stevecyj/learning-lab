## 重點整理

### SQL 是什麼

SQL 是一種用來跟資料庫溝通的程式語言。常見的程式語言如果要跟資料庫溝通，通常都得透過 SQL 這種語言來介接。

Python 也不例外。如果要用 Python 跟其他資料庫溝通，就需要了解 SQL 的語言。
