# 模組 26：SQLite 的新增、查詢、更新與刪除

## 這堂課在講什麼

本節教你用 SQLite 做四個基本操作：新增資料（INSERT）、查詢資料（SELECT）、更新資料（UPDATE）、刪除資料（DELETE）。這四個動作都是透過 `execute()` 執行對應的 SQL 語法完成。

## 學完要會什麼

- 知道 `INSERT INTO ... VALUES` 的語法怎麼寫。
- 知道用 `?` 佔位符搭配 tuple 參數插入資料，而不是直接把變數拼進 SQL 字串。
- 知道插入、更新、刪除資料後要呼叫 `commit()`，變更才會真正寫入資料庫。
- 知道 `SELECT *` 跟 `SELECT` 特定欄位的差別，以及 `WHERE` 子句怎麼加條件。
- 知道兩種取出查詢結果的寫法：用 for 迴圈直接跑 `execute()`，或用 `fetchall()` 一次取出全部資料。
- 知道 `UPDATE` 跟 `DELETE` 都要搭配 `WHERE` 條件，指定要改或刪哪一筆資料。

## 重點整理

### INSERT INTO：插入資料

基本語法是 `INSERT INTO 資料表名稱 VALUES (值1, 值2, ...)`。

### 用 ? 佔位符插入資料

如果要插入的值是變數（例如使用者輸入的內容），可以先把這些值包成一個 tuple，SQL 語法裡用問號 `?` 當佔位符，再用 `connect.execute(SQL, x)` 把 tuple `x` 傳進去。SQLite 會依照順序把 tuple 裡的值帶入每個問號：第一個值對應第一個問號、第二個值對應第二個問號，以此類推。

### commit()：真正寫入資料

用 `execute()` 執行 INSERT 之後，資料還沒有真正寫進資料庫，要呼叫 `connect.commit()` 才會確定寫入。UPDATE 和 DELETE 也一樣，執行完都要 `commit()`。

### SELECT *：查詢所有欄位

`SELECT * FROM 資料表名稱` 的 `*` 代表資料表裡的所有欄位。查詢結果可以用 for 迴圈跑過 `execute(...)` 逐筆印出來。

### SELECT 特定欄位

只想抓某個欄位的話，把 `*` 換成欄位名稱即可，例如 `SELECT name FROM students` 就只會抓出 name 這個欄位；也可以一次指定多個欄位，例如 `SELECT name, gender FROM students`。

### WHERE：加條件查詢

在 SELECT 語法後面加上 `WHERE 欄位 = 值`，可以限制查詢結果只回傳符合條件的資料，例如 `WHERE gender = 'female'` 就只會抓出性別是女生的資料。

### UPDATE：更新資料

語法是 `UPDATE 資料表名稱 SET 欄位 = 新值 WHERE 條件`，例如 `UPDATE students SET name = 'tomy' WHERE id = 1`，代表把 id 等於 1 那筆資料的 name 改成 tomy。

### DELETE：刪除資料

語法是 `DELETE FROM 資料表名稱 WHERE 條件`，例如 `DELETE FROM students WHERE id = 2`，代表把 id 等於 2 那筆資料整筆刪除。

### 取出查詢結果的兩種寫法

第一種：直接用 for 迴圈跑 `c.execute(SQL)`，每一輪迴圈拿到的 record 就是一筆資料，用 `record[0]`、`record[1]`、`record[2]` 依序取出各欄位的值。

第二種：先用 `connect.execute(SQL)` 拿到結果，再呼叫 `.fetchall()` 把所有資料一次轉成一個 tuple（裡面每筆資料也是一個 tuple），存到變數（例如 `allstudents`）後，再用 `for student in allstudents` 把每筆資料取出來。

## 範例與操作

### 範例一：插入資料到 example 資料表

```python
cursor.execute('INSERT INTO example VALUES (1, 2, 3)')
```

在 example 這個資料表裡插入固定的三個數字值。

### 範例二：查詢 example 資料表的所有內容

```python
for row in c.execute('SELECT * FROM example'):
    print(row)
```

### 範例三：用迴圈讓使用者輸入資料，插入到 students 資料表

```python
import sqlite3

connect = sqlite3.connect('myddata.db')

while True:
    new_id = input('請輸入 id：')
    new_name = input('請輸入 name：')
    new_gender = input('請輸入 gender：')
    x = (new_id, new_name, new_gender)

    SQL = 'INSERT INTO students VALUES (?, ?, ?)'
    connect.execute(SQL, x)
    connect.commit()

    if input('繼續輸入嗎？(y/n)：') != 'y':
        break
```

課堂示範依序輸入了三筆資料：

- id=1, name=Isaac, gender=male
- id=2, name=andy, gender=male
- id=3, name=amy, gender=female

用 SQLite Browser 打開 myddata.db，可以看到 students 資料表裡確實有 id、name、gender 三個欄位，剛剛插入的三筆資料也都在裡面，代表插入成功。

### 範例四：查詢 students 資料表的所有內容（for 迴圈寫法）

```python
import sqlite3

connect = sqlite3.connect('myddata.db')
c = connect.cursor()

for record in c.execute('SELECT * FROM students'):
    print(record)
    print(record[0], record[1], record[2])
```

`record[0]` 是第一個欄位（id）、`record[1]` 是第二個欄位（name）、`record[2]` 是第三個欄位（gender），以此類推。

### 範例五：查詢 students 資料表的所有內容（fetchall 寫法）

```python
result = connect.execute('SELECT * FROM students')
allstudents = result.fetchall()

for student in allstudents:
    print(student)
```

`fetchall()` 會把所有查詢結果一次轉換成一個 tuple。

### 範例六：只查詢特定欄位

```python
for record in c.execute('SELECT name FROM students'):
    print(record)
```

這樣只會抓出 name 這個欄位的內容。

### 範例七：查詢時加條件

```python
for record in c.execute("SELECT name, gender FROM students WHERE gender = 'female'"):
    print(record)
```

限制了 `gender = 'female'`，這個例子只會抓出 amy 這一筆。

### 範例八：更新資料

```python
connect.execute("UPDATE students SET name = 'tomy' WHERE id = 1")
connect.commit()

for record in c.execute('SELECT name FROM students'):
    print(record)
```

執行後，原本 id 等於 1 的名稱 Isaac 會變成 tomy。

### 範例九：刪除資料

```python
connect.execute('DELETE FROM students WHERE id = 2')
connect.commit()

for record in c.execute('SELECT * FROM students'):
    print(record)
```

執行後，id 等於 2 那筆資料（andy）會被刪除；重新整理 SQLite Browser 也會看到這筆資料消失。

## 常見誤解／注意事項

- 用 `?` 佔位符時，tuple 裡值的順序要跟問號的順序一一對應，第一個值對應第一個問號，依此類推。
- 用 `execute()` 做完 INSERT、UPDATE、DELETE 之後，一定要呼叫 `commit()`，變更才會真正寫進資料庫。
- `SELECT *` 是抓出所有欄位，只想要部分欄位時要把 `*` 換成明確的欄位名稱。
- `WHERE` 子句是用來加限制條件；不加的話就會查詢（或修改、刪除）資料表裡所有符合的資料。

## 一句話回顧

SQLite 的新增、查詢、更新、刪除都是透過 `execute()` 執行對應的 SQL 語法（INSERT INTO、SELECT、UPDATE、DELETE），插入或修改資料後別忘了呼叫 `commit()`，才會真正寫入。
