# 模組 26：用 SQLite 建立資料庫與資料表

## 這堂課在講什麼

本節教你怎麼用 SQLite 建立資料庫與資料表：怎麼用 `execute()` 下 SQL 指令、怎麼用 `sqlite3.connect()` 開資料庫、以及兩種建立資料表的寫法（用 cursor、不用 cursor）。

## 學完要會什麼

- 知道用 `cursor.execute()` 執行 SQL 指令的寫法。
- 知道 `DROP TABLE IF EXISTS` 與 `CREATE TABLE` 的語法用途。
- 知道 `sqlite3.connect()` 的行為：檔案存在就連線，不存在就建立新檔案。
- 知道操作完資料庫要記得關閉連線（用了 cursor 的話也要關閉 cursor）。
- 知道 `connect.execute()` 可以省略建立 cursor 的步驟，寫法更精簡。

## 重點整理

### 用 execute() 下 SQL 指令

想用 SQLite 建立資料庫和資料表，基本寫法是在 cursor 物件後面接 `execute()`，再把 SQL 指令當成字串傳進去，例如 `cursor.execute(SQL 指令)`。

### DROP TABLE IF EXISTS：刪除資料表

`DROP TABLE IF EXISTS example` 的意思是：如果存在一個叫 `example` 的資料表，就把它刪除。

### CREATE TABLE：建立資料表與欄位

`CREATE TABLE example` 會建立一個名為 `example` 的資料表。這個資料表底下可以定義欄位，例如 `date`（文字型別）、`name`（文字型別）、`score`（文字型別）這三個欄位。

### sqlite3.connect() 的行為

用 `sqlite3.connect()` 連線資料庫時：如果指定的資料庫檔案已經存在，就會連線到那個檔案；如果不存在，就會建立一個新的資料庫檔案。

### 用完資料庫記得關閉連線

不管有沒有用 cursor，操作完資料庫都要記得關閉。有開 cursor 的話，要連 cursor 一起關掉。

### 兩種建立資料表的寫法：用 cursor vs 不用 cursor

一種寫法是先用 `connect.cursor()` 產生一個 cursor，再用 `cursor.execute()` 下 SQL 指令。另一種寫法是省略 cursor，直接用 `connect.execute()` 下 SQL 指令，寫起來更精簡，是課程比較推薦的做法。

## 範例與操作

### 範例一：建立資料庫（不建資料表）

```python
import sqlite3

connect = sqlite3.connect('myddata.db')

connect.close()
```

執行後，資料夾裡會多出一個 `myddata.db` 檔案。

### 範例二：用 cursor 建立資料表 students

```python
import sqlite3

connect = sqlite3.connect('myddata2.db')
cursor = connect.cursor()

cursor.execute('''
CREATE TABLE students (
    id INTEGER,
    name TEXT,
    gender TEXT
)
''')

cursor.close()
connect.close()
```

`students` 資料表底下有 `id`（整數型別）、`name`（文字型別）、`gender`（文字型別）三個欄位。執行後，資料夾裡會多出 `myddata2.db`；用上一節介紹的 SQLite Browser 打開這個檔案，可以確認 `students` 資料表底下確實有這三個欄位，跟程式碼寫的一致。

### 範例三：不用 cursor，直接用 connect.execute()

```python
import sqlite3

connect = sqlite3.connect('myddata3.db')

connect.execute('''
CREATE TABLE students (
    id INTEGER,
    name TEXT,
    gender TEXT
)
''')

connect.close()
```

這個寫法省略了建立 cursor 的步驟，直接對 `connect` 呼叫 `execute()`，程式碼更精簡。執行後，資料夾裡會多出 `myddata3.db`。

## 常見誤解／注意事項

- 建立資料庫的步驟本身不會自動建立資料表；一個資料庫底下可以有多張資料表，要另外用 `CREATE TABLE` 建立。
- `sqlite3.connect()` 不會因為檔案不存在就報錯，而是會直接建立一個新檔案。
- 用了 cursor 的寫法，操作完除了關閉連線，也要記得把 cursor 關掉。

## 一句話回顧

用 `sqlite3.connect()` 開資料庫、用 `execute()` 下 SQL 指令建表，操作完記得關閉連線；不想額外建立 cursor 的話，也可以直接呼叫 `connect.execute()`，讓程式碼更精簡。
