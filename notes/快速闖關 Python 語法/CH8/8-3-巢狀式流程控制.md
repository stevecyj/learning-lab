## 一、什麼是巢狀式流程控制？

「巢狀」就是把一個流程控制結構放進另一個流程控制結構的區塊裡。例如外層的 `if` 成立後，還要用另一個 `if` 做更細的判斷：

~~~python
if x > 10:
    print("above ten")

    if x > 20:
        print("and also above 20")
    else:
        print("but not above 20")
~~~

這裡有兩層條件：

1. **外層 `if x > 10`**：先判斷 `x` 是否超過 10。
2. **內層 `if x > 20`**：只有外層成立時，才會再判斷 `x` 是否超過 20。

因此，內層判斷不是每次都執行；`x <= 10` 時，整個外層區塊都會跳過。

---

## 二、縮排表示程式碼屬於誰

Python 用縮排界定區塊。上例中，所有縮排一層的程式都屬於外層的 `if x > 10`：

~~~text
if x > 10:                    ← 外層條件
    print("above ten")        ← 屬於外層 if
    if x > 20:                ← 也屬於外層 if
        print(...)             ← 屬於內層 if
    else:                     ← 配對內層 if
        print(...)             ← 屬於內層 else
~~~

重點是：`else` 要和它所配對的 `if` **對齊**。在此例中，內層的 `else` 與 `if x > 20:` 有相同縮排，所以它不屬於外層 `if x > 10:`。

Python 官方教學說明，`if` 可以搭配零個或多個 `elif`，而 `else` 是可選的；巢狀結構同樣依賴縮排來表示每個區塊的範圍。[Python 官方教學：`if` Statements](https://docs.python.org/3/tutorial/controlflow.html#if-statements)

## 三、逐步追蹤教材範例

### 情況 A：`x = 25`

~~~python
x = 25

if x > 10:
    print("above ten")

    if x > 20:
        print("and also above 20")
    else:
        print("but not above 20")
~~~

執行順序：

1. `25 > 10` 是 `True`，進入外層 `if`。
2. 輸出 `above ten`。
3. `25 > 20` 是 `True`，進入內層 `if`。
4. 輸出 `and also above 20`。

結果：

~~~text
above ten
and also above 20
~~~

### 情況 B：`x = 15`

1. `15 > 10` 是 `True`，進入外層 `if`。
2. 輸出 `above ten`。
3. `15 > 20` 是 `False`，因此內層 `if` 的 `else` 執行。
4. 輸出 `but not above 20`。

結果：

~~~text
above ten
but not above 20
~~~

### 情況 C：`x = 8`

`8 > 10` 是 `False`，外層區塊完全不執行，因此沒有任何輸出。內層 `if` 根本不會被檢查。

## 四、用決策路徑理解程式

~~~text
x > 10？
├─ 否：結束（沒有輸出）
└─ 是：輸出 above ten
   └─ x > 20？
      ├─ 是：輸出 and also above 20
      └─ 否：輸出 but not above 20
~~~

巢狀 `if` 很適合表達「先通過基本條件，再做更細的分類」。例如：先確認使用者已登入，再判斷是否具有管理員權限。

## 五、常見錯誤

### 1. 以為內層 `else` 屬於外層 `if`

以下縮排會讓 `else` 配對到外層 `if`，語意與教材範例不同：

~~~python
if x > 10:
    print("above ten")
    if x > 20:
        print("and also above 20")
else:
    print("x is 10 or below")
~~~

這個版本中，`x = 15` 時不會輸出 `but not above 20`；因為外層條件成立，而外層的 `else` 不會執行。

### 2. 混用 Tab 與空白

同一份 Python 程式應使用一致的縮排。慣例是每層使用 **4 個空白**；不要混用 Tab 與空白，以免產生 `IndentationError` 或難以閱讀的結構。

## 六、動手練習：先預測，再執行

不執行程式，先寫下下列各值的輸出：`x = 8`、`x = 10`、`x = 11`、`x = 20`、`x = 21`。

~~~python
if x > 10:
    print("above ten")
    if x > 20:
        print("and also above 20")
    else:
        print("but not above 20")
~~~

答案：

| `x` | 輸出 |
| ---: | --- |
| 8 | 無輸出 |
| 10 | 無輸出 |
| 11 | `above ten`、`but not above 20` |
| 20 | `above ten`、`but not above 20` |
| 21 | `above ten`、`and also above 20` |
