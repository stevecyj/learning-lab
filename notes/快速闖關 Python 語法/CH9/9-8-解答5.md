# 9-8 解答 5

## 這堂課在講什麼

本節解答兩題練習：計算兩個向量之間的直線距離，以及判斷字串是否為 palindrome（回文）。兩題都利用 `for` 迴圈逐一處理資料。

## 學完要會什麼

- 逐一計算兩個向量相同位置元素的差值平方，並累加結果。
- 對累加的平方差開根號，得到兩個向量的直線距離。
- 由字串尾端往前走，組出反轉後的字串。
- 比較原字串與反轉字串，判斷是否為 palindrome。

## 重點整理

### 第一題：計算兩個向量的直線距離

題目要求輸入兩個向量，但字幕沒有交代輸入格式；以下以 `vector1 = [1, 2, 1]`、`vector2 = [3, 4, 2]` 示範計算核心。先計算每個相同位置的差值平方，再全部加總：

```text
(1 - 3)² + (2 - 4)² + (1 - 2)² = 9
```

最後對加總結果開根號，也就是取 `0.5` 次方，距離為 `3`。

程式先把累積用的 `diff_sum` 設為 `0`，接著用 `range(len(vector1))` 走訪每個索引位置。每一圈都把兩個向量在該位置的差值平方加進 `diff_sum`。

```python
vector1 = [1, 2, 1]
vector2 = [3, 4, 2]

diff_sum = 0

for i in range(len(vector1)):
    diff_sum += (vector1[i] - vector2[i]) ** 2

distance = diff_sum ** 0.5
print(distance)
```

輸出結果：

```text
3.0
```

### 第二題：判斷 palindrome

palindrome 指的是正著讀和反著讀都相同的字串。例如 `aabbaa` 反轉後仍是 `aabbaa`，因此它是 palindrome。

先準備空字串 `reverse_word`，再從 `word` 的最後一個位置往前走。每一圈把目前的字元加到 `reverse_word` 後面，就能逐步組出反轉字串。

```python
word = input("請輸入字串：")
reverse_word = ""

for i in range(len(word) - 1, -1, -1):
    reverse_word += word[i]

if reverse_word == word:
    print("palindrome")
else:
    print("not a palindrome")
```

例如輸入 `aabbaa` 時，`reverse_word` 會是 `aabbaa`，和原本的 `word` 相同，因此程式會印出 `palindrome`。

## 常見誤解／注意事項

- 計算距離時，要先把每一個差值平方後再加總；不能先把所有差值相加再平方。
- 兩個向量要能用相同的索引位置逐一比較。
- `range(len(word) - 1, -1, -1)` 從最後一個索引開始，每次減 `1`，直到索引 `0`。
- `reverse_word` 要先設為空字串 `""`，才能在迴圈中逐步加上字元。

## 一句話回顧

向量距離靠累加各位置的差值平方後開根號；回文判斷則把字串反轉後，和原字串比較。
