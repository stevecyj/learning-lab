# 9-3 巢狀式迴圈

## 這堂課在講什麼

巢狀式迴圈就是「迴圈裡還有迴圈」。概念和巢狀式流程判斷相同：`if` 裡可以有 `if`，`for` 迴圈裡也可以再放一個 `for` 迴圈。

外層迴圈每執行一圈，內層迴圈都會從頭到尾執行完畢。因此，內層的變數 `j` 變化得比外層的 `i` 快。

## 學完要會什麼

- 看懂外層與內層迴圈的執行順序。
- 用巢狀式迴圈印出正方形、遞增三角形與遞減三角形的星號。
- 讀懂 `range(start, stop, step)`，尤其是遞減的寫法。

## 重點整理

### 外層一圈，內層完整跑完

以 `n = 5` 為例，當 `i = 0` 時，內層的 `j` 會依序跑完 `0`、`1`、`2`、`3`、`4`。接著 `i` 才會變成 `1`，而 `j` 又重新從 `0` 跑到 `4`。

可以把它理解成：

```text
i = 0 時，j 跑 5 圈
i = 1 時，j 再跑 5 圈
i = 2 時，j 再跑 5 圈
...
```

若想直接觀察執行順序，可以先印出每一圈的 `i` 和 `j`。

```python
n = 5

for i in range(n):
    for j in range(n):
        print(i, j)
```

### 印出 5 × 5 的星號正方形

```python
n = 5

for i in range(n):
    for j in range(n):
        print("*", end="")
    print()
```

輸出結果：

```text
*****
*****
*****
*****
*****
```

內層迴圈負責印出一列中的 5 個星號。`print("*", end="")` 將 `print()` 預設的換行改成空字串，所以星號會留在同一行。

內層迴圈結束後，外層迴圈中的 `print()` 才會執行，用來換到下一行。若少了這一行，所有星號都會印在同一行。

### 用 `i` 控制內層的執行次數

內層不一定要固定執行 5 次，也可以讓它依外層的 `i` 而改變。

```python
n = 5

for i in range(n):
    for j in range(i):
        print("*", end="")
    print()
```

這段程式中，`i` 依序是 `0` 到 `4`。因此 `range(i)` 的次數會由 `0` 次逐漸增加到 `4` 次，印出的星號會一列比一列多。第一列不會印星號，因為 `range(0)` 不會執行。

```text

*
**
***
****
```

課程將這種由少到多的排列稱為上三角形。

### 讓 `range()` 遞減

若要讓 `i` 從大到小變化，可以使用：

```python
range(n, 0, -1)
```

以 `n = 5` 為例，`range(5, 0, -1)` 會產生：

```text
5, 4, 3, 2, 1
```

把遞減的 `i` 放進內層迴圈，就能讓每列的星號逐漸變少。

```python
n = 5

for i in range(n, 0, -1):
    for j in range(i):
        print("*", end="")
    print()
```

輸出結果：

```text
*****
****
***
**
*
```

課程將這種由多到少的排列稱為下三角形。

### `range()` 的三個參數

`range(start, stop, step)` 可以指定起點、停止前的位置與每次變化的間隔。

```python
for i in range(1, 10, 2):
    print(i)
```

輸出為 `1`、`3`、`5`、`7`、`9`：從 `1` 開始，每次加 `2`，但不包含 `10`。

## 練習方式

先把正方形範例中印星號的那一行暫時註解掉，只印出 `i` 和 `j`，觀察內外層迴圈的執行順序。理解後再放回印星號的程式碼，對照每次換行發生的位置。

## 常見誤解／注意事項

- `j` 不是只跑一次；每次外層的 `i` 改變，`j` 都會重新完整執行。
- `range(i)` 的執行次數取決於當下的 `i`。`i = 0` 時不會執行，`i = 4` 時會執行 4 次。
- `range(n, 0, -1)` 不包含 `0`，所以 `n = 5` 時會得到 `5` 到 `1`。
- 印圖形時，內層的 `print("*", end="")` 負責同一列的內容；內層結束後的 `print()` 負責換行。

## 一句話回顧

巢狀式迴圈中，外層每跑一圈，內層就會完整跑完一次；改變內層 `range()` 的次數，就能印出不同形狀。
