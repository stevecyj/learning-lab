# 快速活用 MySQL，精準設計關聯式資料庫（錄播課教學銜接單元）

## 這份清單在講什麼

這是「快速活用 MySQL」課程的錄播課銜接單元清單，涵蓋單元 2 到單元 17，內容從資料庫安裝、命令列與圖形介面操作，到關聯式資料庫概念與 SQL 基本操作。這些單元要在直播專案課之前錄播完成，作為進入「專案2：成績查詢系統」的先修內容。

## 銜接單元清單

1. 單元2. MySQL 資料庫介紹與安裝
2. 單元3. 命令列啟動 MySQL
3. 單元4. Workbench 管理工具安裝
4. 單元5. Workbench 連線與偏好設定
5. 單元6. 圖形介面管理 MySQL
6. 單元7. 資料庫介紹
7. 單元8. 關聯式資料庫概論
8. 單元9. SQL 介紹
9. 單元10. 建立/刪除資料庫
10. 單元11. 表格與欄位說明
11. 單元12. 表格建立、修改與刪除
12. 單元13. 新增資料與自動編號
13. 單元17. 資料查詢
