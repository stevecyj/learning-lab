# 9-5 Practice 2：檢討

## 這堂課在講什麼

本節檢討三題練習：找出指定範圍內同時能被 `7` 和 `5` 整除的數字、反轉輸入字串，以及用巢狀式迴圈印出九九乘法表。

## 學完要會什麼

- 用 `range()` 走訪指定的整數範圍，並用 `%` 同時判斷兩個整除條件。
- 把符合條件的數字存進串列，再用 `join()` 組成輸出字串。
- 用倒序索引或串列的 `reverse()` 反轉字串。
- 用兩層 `for` 迴圈列出九九乘法表。

## 重點整理

### 第一題：列出 1,500 到 2,700 間同時能被 7 和 5 整除的數字

`range()` 不包含停止位置，因此要走訪到 `2700`，停止位置要寫成 `2701`。每個數字都用 `%` 檢查：餘數為 `0` 代表可以整除。符合兩個條件時，先把數字轉成字串再加入串列，最後用 `",".join()` 以逗號連接。

```python
numbers = []

for i in range(1500, 2701):
    if i % 7 == 0 and i % 5 == 0:
        numbers.append(str(i))

print(",".join(numbers))
```

也可以直接累加字串，但每次都會在數字後面加上逗號：

```python
my_string = ""

for x in range(1500, 2701):
    if x % 7 == 0 and x % 5 == 0:
        my_string += str(x) + ","

print(my_string[:-1])
```

`my_string[:-1]` 表示從開頭取到倒數第二個字元，所以會排除最後多出來的逗號。

### 第二題：反轉輸入的字串

第一種做法是從字串的最後一個索引開始，每次往前移一格。`range(len(word) - 1, -1, -1)` 的三個參數依序是起點、停止位置與步長；停止位置不包含 `-1`，因此索引會走到 `0`。

```python
word = input("請輸入字串：")

for character in range(len(word) - 1, -1, -1):
    print(word[character], end="")
```

另一種做法是先把字串轉成串列。串列的 `reverse()` 會直接把元素順序反轉，再用空字串的 `join()` 把每個字元接回字串。

```python
word = input("請輸入字串：")
characters = list(word)
characters.reverse()

reversed_word = "".join(characters)
print(reversed_word)
```

### 第三題：用巢狀式迴圈印出九九乘法表

外層迴圈負責第一個乘數 `i`，內層迴圈負責第二個乘數 `j`。兩者都要從 `1` 走到 `9`，所以使用 `range(1, 10)`。每一圈先計算 `result = i * j`，再用 `.format()` 放入輸出字串。

```python
for i in range(1, 10):
    for j in range(1, 10):
        result = i * j
        print("{} x {} = {}".format(i, j, result))
```

課程範例另外加入格式控制，讓等號後的數字排列得更整齊；這部分尚未正式教學。現階段能正確印出每一組「乘數 x 乘數 = 結果」即可。

## 常見誤解／注意事項

- `range(1500, 2701)` 與 `range(1, 10)` 都不包含最後一個停止位置。
- 同時符合兩個條件時，要使用 `and`；`i % 7 == 0` 與 `i % 5 == 0` 都必須成立。
- `join()` 的串列元素必須是字串，因此第一題加入串列前要使用 `str(i)`。
- 字串不可直接用 `reverse()`；要先以 `list()` 轉成串列。`reverse()` 會直接修改原本的串列。
- 字串切片的 `[:-1]` 會拿掉最後一個字元；在這題中用來移除最後多出來的逗號。

## 一句話回顧
