# 9-4 Practice 1：檢討

## 這堂課在講什麼

本節檢討四題迴圈練習：用規律印出金字塔、計算階乘、統計串列中的奇偶數，以及用 `continue` 跳過指定數字。

## 學完要會什麼

- 從圖形中找出每一列的規律，再用迴圈印出來。
- 用累乘的方式計算正整數的階乘。
- 逐一檢查串列元素，分別統計奇數與偶數的數量。
- 用 `continue` 略過不需要處理的迴圈項目。

## 重點整理

### 第一題：印出金字塔

先輸入金字塔的層數 `level`。每一列要印出的內容由「空白」和「星號」組成：

- 第 `i` 列前面的空白有 `level - i - 1` 個。
- 第 `i` 列的星號有 `2 * i + 1` 個，因此會依序是 `1`、`3`、`5`、`7`、`9`。

字串相加會直接連接，字串乘上整數則會重複該字串，可以用這兩個規則組出每一列。

```python
level = int(input("請輸入金字塔層數："))

for i in range(level):
    spaces = " " * (level - i - 1)
    stars = "*" * (2 * i + 1)
    print(spaces + stars)
```

例如 `level = 5` 時，會印出：

```text
    *
   ***
  *****
 *******
*********
```

### 第二題：計算 factorial（階乘）

`factorial` 是階乘。例如 `5!` 等於 `5 × 4 × 3 × 2 × 1`，而 `4!` 等於 `4 × 3 × 2 × 1 = 24`。

計算時先把累積結果設為 `1`，再從 `1` 乘到輸入的數字。`range(1, number + 1)` 的停止位置不包含 `number + 1`，所以實際會算到 `number`。

```python
number = int(input("請輸入整數："))
result = 1

for i in range(1, number + 1):
    result = result * i

print(result)
```

每一圈都把目前的 `i` 乘進 `result`，最後的 `result` 就是階乘結果。

### 第三題：統計 list 中的奇數與偶數

先準備兩個計數變數，初始值都設為 `0`。逐一取出串列中的數字後，用 `% 2` 判斷是否能被 `2` 整除：餘數為 `0` 是偶數，否則是奇數。

```python
numbers = [1, 2, 3, 4, 5, 6]
odd_count = 0
even_count = 0

for x in numbers:
    if x % 2 == 0:
        even_count += 1
    else:
        odd_count += 1

print("偶數個數：", even_count)
print("奇數個數：", odd_count)
```

### 第四題：用 `continue` 跳過指定數字

題目要印出 `0` 到 `6`，但遇到 `2` 和 `6` 時不印。`continue` 會立刻結束目前這一圈，回到迴圈開頭檢查下一個數字。

```python
for x in range(7):
    if x == 2 or x == 6:
        continue
    print(x)
```

輸出為：

```text
0
1
3
4
5
```

## 常見誤解／注意事項

- 金字塔的第一列只有 `1` 個星號，之後每列增加 `2` 個；空白則每列少 `1` 個。
- `range()` 不包含停止位置。要走訪 `1` 到 `number`，停止位置要寫成 `number + 1`；要包含 `6`，要使用 `range(7)`。
- 階乘的累積變數必須從 `1` 開始。若從 `0` 開始，後續相乘的結果都會是 `0`。
- `continue` 不會結束整個迴圈，只會跳過目前的這一圈。

## 一句話回顧
