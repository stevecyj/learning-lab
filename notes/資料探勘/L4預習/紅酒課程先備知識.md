# 紅酒資料課程先備知識

紅酒資料集的兩份 Notebook 是把前面學過的資料處理與迴歸步驟串起來的綜合練習，不是第一次介紹這些觀念的教材。

## 最低先備

開始前不必完整學完 NumPy、Pandas 或 EDA；先具備下列內容即可。

1. **資料形狀（shape）**
   - `X` 是二維特徵資料，形狀通常是 `(樣本數, 特徵數)`。
   - `y` 是一維目標資料，形狀通常是 `(樣本數,)`。

2. **選取資料與欄位**
   - 能從 DataFrame 分離特徵 `X` 與目標 `y`。
   - 能看懂 NumPy 的 `X[:, mask]`，或 Pandas 的 `X.loc[:, mask]`：保留所有 row，依照 `mask` 決定保留哪些 column。

3. **scikit-learn 的固定流程**

   ```text
   分離 X 與 y
   → train_test_split
   → 用 X_train fit StandardScaler
   → 用同一個 scaler transform X_train 與 X_test
   → model.fit
   → predict
   → 用 MSE、R² 評估
   ```

   `StandardScaler` 只能從訓練資料 `X_train` 計算轉換規則；測試資料只能套用同一組規則。

## Part 1 額外需要

要知道 `PolynomialFeatures` 會根據原始特徵建立平方項與特徵交互項，因此 `X_poly` 的 column 數量通常比原本的 `X` 多。

## Part 2 額外需要

要知道 Lasso 會為每個特徵產生係數；`model.coef_ != 0` 會得到布林 `mask`。`True` 代表保留該特徵，`False` 代表移除該特徵。

## 最省時的預習順序

1. 從 `sklearn複習.ipynb` 補資料切分、標準化與 MSE／R²。
2. 從 `迴歸演算法複習.ipynb` 補 Polynomial Regression。
3. 開始 `紅酒資料集預測_part1.ipynb`。
4. 再補 Lasso 與布林 mask，開始 `紅酒資料集預測_part2.ipynb`。

EDA、缺失值處理與異常值處理是本課程閱讀順序上的先備：它們幫助你判斷資料能否直接建模。紅酒 Notebook 的程式未必會因為不懂這些觀念而無法執行，但不應因此跳過 EDA。
