## 最值得先補的前置知識

不需要先把 NumPy 和 Pandas 的所有功能讀完。這堂課最依賴的是 shape、indexing、axis，以及 scikit-learn 的固定資料流程。

### 一、先看懂 shape

NumPy 陣列的 `shape` 用來描述每一維有多少個位置：

```text
一維：(元素數量,)
二維：(row 數量, column 數量)
三維：(第 0 維, 第 1 維, 第 2 維)
```

例如：

```python
X.shape == (100, 11)
```

代表 `X` 有 100 筆資料，每筆資料有 11 個特徵。

在 scikit-learn 中，常見的資料形狀是：

```text
X：二維，(樣本數, 特徵數)
y：一維，(樣本數,)
```

這是整堂課最重要的資料契約。每執行一次選取、轉換或切分，都應該確認資料是否仍符合這個格式。

### 二、把 indexing 分成三類學

不要把所有索引語法混在一起背。

#### 1. NumPy 位置索引

```python
array[2]
array[2, 3]
array[:, 3]
array[:, mask]
```

#### 2. Pandas 標籤索引

```python
df['Age']
df[['Age', 'Fare']]
df.loc[rows, columns]
```

#### 3. 條件篩選

```python
df[df['Fare'] > 300]
df.loc[df['Fare'] > 300, 'Fare']
```

每次看到 indexing，都先問：

1. 現在選的是 row 還是 column？
2. 選取後的結果是一維還是二維？

例如：

```python
df['Age']       # Series，一維
df[['Age']]     # DataFrame，二維
```

兩者取得的都是 `Age`，但結果的資料結構與 shape 不同。這個差異會影響資料能不能直接交給 scikit-learn。

### 三、不要只用橫向、縱向背 axis

比較穩定的理解方式是：

> `axis=n` 表示操作沿著第 n 維進行。聚合操作通常會讓該維消失。

假設：

```python
a.shape == (3, 4)
```

代表 `a` 有 3 rows、4 columns。

執行：

```python
a.mean(axis=0)
```

程式會把第 0 維的 3 rows 聚合掉，每個 column 留下一個平均數，因此結果的 shape 是：

```text
(4,)
```

執行：

```python
a.mean(axis=1)
```

程式會把第 1 維的 4 columns 聚合掉，每一個 row 留下一個平均數，因此結果的 shape 是：

```text
(3,)
```

不過，不同函式對 axis 執行的動作不同，所以必須把「函式動作」和 `axis` 一起讀。

```python
df.drop('Season', axis=1)
```

這裡是從 column 軸刪除 `Season`。

```python
pd.concat([left, right], axis=1)
```

這裡是沿著 column 軸把資料排在彼此旁邊。

可以先這樣區分：

- `mean(axis=0)`：聚合第 0 維。
- `drop(..., axis=1)`：從 column 軸刪除資料。
- `concat(..., axis=1)`：沿 column 軸增加或對齊資料。

### 四、建立 scikit-learn 固定流水線

先記住資料的生命週期，不要一開始就背每個模型的參數：

```text
原始 DataFrame
→ 分離 X 與 y
→ train/test split
→ 用 X_train fit 前處理器
→ transform X_train
→ 用同一個前處理器 transform X_test
→ model.fit(X_train, y_train)
→ model.predict(X_test)
→ metric(y_test, y_pred)
```

關鍵規則是：

> 測試資料只能套用訓練資料算出的轉換規則，不能用測試資料重新 `fit()`。

正確流程如下：

```python
scaler = StandardScaler().fit(X_train)

X_train = scaler.transform(X_train)
X_test = scaler.transform(X_test)
```

`fit(X_train)` 會從訓練資料算出平均數和標準差。之後兩份資料必須使用同一組數值轉換，才不會讓測試資料提前影響模型流程。
