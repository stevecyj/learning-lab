一個選 Java，一個照顧專案。

🧰

SDKMAN!

幫你換 JDK

sdk use java 25-tem
↕
sdk use java 21-tem
🎒

Gradle Wrapper

專案自己的工具箱

./gradlew test ./gradlew run ./gradlew build

第一次準備

1
裝 SDKMAN!curl -s "https://get.sdkman.io" | bash
2
裝 Javasdk list java
sdk install java <清單中的 Java 25 ID>
3
告訴專案用哪個 Javasdk env init

專案盒子裡

📄 .sdkmanrc　← JDK 版本
🔧 gradlew　← Gradle 啟動鈕
📁 gradle/wrapper/　← Gradle 版本
📄 build.gradle.kts　← 套件清單

每天只做這樣

📂 進專案 → 🧰 選 JDK → 🎒 跑 Gradle

cd hello-java sdk env ./gradlew run

若開啟 SDKMAN! 自動切換，連 sdk env 都可以省略。
